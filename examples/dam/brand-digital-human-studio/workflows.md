# 操作流程与异常

创作者从资产库选择图片，或输入需求查看规则候选；确认人物、商品、场景后编辑分镜，提交任务，完成后检查成品并复用。声音记录只关联资料，没有声线生成。

模拟任务为 queued → generating → completed，约 22 秒；取消保留配置，失败可重试。输出为内置样片，不按脚本生成实际表演。

独立真实模式先配置本机代理和客户账号，再查询估算并手动提交。状态由平台回读，不用本地计时伪造百分比。仅 queued 可请求取消，开始后不能靠关闭页面停止扣费。真实重试带入旧配置，由用户再次确认提交。

提交未收到明确响应时，保留请求证据到平台核对，不盲目重发。查询失败提示异常并保留已有状态。余额、权限、限流和内容拒绝不伪造成功。

人物身份照片创建与参考图生成是独立收费操作，状态完成后方可生成参考图。关闭 Soul 面板不会取消任务，当前需保留面板读取图像结果并及时另存文件。

审核是本地标记，没有生产审核角色权限或驳回流程。下载实际媒体与导出 JSON 配置是不同动作；无自动永久归档。重置不取消平台任务，不删除平台人物参考。
