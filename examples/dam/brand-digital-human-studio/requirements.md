# 业务需求与技术验证范围

## 已抽象的业务问题

品牌内容制作需要复用固定人物、商品和场景素材，减少重复上传，按新需求生成候选视频并审核。长期资料可控和自助创作是目标；主体新表情、全身动作、穿戴细节、指定声线和跨场景稳定性属于生成质量门槛。

公开需求已抽象，不包含客户名称、原始聊天、真人素材、商务报价或账号数据。虚构人设不是客户真人建模成果。

## 当前范围

- 图片入库、分类筛选与收藏，规则或可选语义解析后的候选确认。
- 创作配置、规则分镜、模拟任务、示意媒体预览与审核、JSON 导出和配置复用。
- 可配置的本机 API 适配：人物照片、Soul ID v2、参考图、参考视频、费用估算、状态、排队取消和下载。
- 目录入口的免费模拟与独立入口的真实验证明确区分。

## 当前未满足

生产账号、企业共享库、授权审核系统、永久文件归档、后台队列、声音克隆、TTS、口型、长片合成和人物模型导出均不在已有完成声明中。生成接口代码不是真实效果证据。

## 待确认

1. 一致性验收是审核后成片合格，还是每次自动生成都必须零偏差？后者当前不承诺。
2. 是否接受人物参考约束的通用生成模型？禁止任何通用模型时需重新选型。
3. 退出需要带走原素材与成品，还是可运行人物模型？当前平台不提供后者。
4. 产品演示是已穿戴展示，还是连续拿取、穿戴、摘取？需要分别验证。
5. 声音服务、允许人工介入、候选次数、成片成本和正式存储范围需另确认。
