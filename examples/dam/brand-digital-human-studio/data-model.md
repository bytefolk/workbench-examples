# 数据模型与生命周期

| 实体         | 关键字段                                             | 当前边界                                                         |
| ------------ | ---------------------------------------------------- | ---------------------------------------------------------------- |
| Asset        | id、kind、name、code、tags、image、Soul ID、更新时间 | 图片/元数据存于当前浏览器；无正式不可变版本、授权范围或多人共享  |
| Draft        | 需求、四类资产关联、模型、画幅、时长、分镜           | 分镜是文字意图，不是精确镜头时间轴                               |
| Task         | 输入快照、状态、平台请求ID、错误、结果URL            | 模拟与真实来源分开；真实结果依赖外部平台                         |
| 成品状态     | approved、favorite、配置快照                         | 浏览器标记；不是已存储的永久文件或服务端审计                     |
| 本机代理记录 | requests、souls、uploads、匿名会话关联               | `.local/` 中的最小 JSON 状态；上传哈希缓存30分钟，不是生产数据库 |

浏览器存储键独立于其他案例。根目录静态演示不读取代理；独立运行使用本案例本机端口与数据目录。

平台文件需要下载到自有存储；媒体地址和配置 JSON 不能代替备份。客户输入及运行数据不入 Git。真人输入的权利与平台使用授权由正式部署流程另行确认。
