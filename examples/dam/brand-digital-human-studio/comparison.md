# 两套数字人工作台对比

比较完整案例 `character-material-library` 中的主入口 `workbench/`，与本案例 `brand-digital-human-studio/workbench/`；前者的简版 `demo/` 不是六页主工作台。核对日期2026-10-14，依据源码和运行验证，非宣传材料。

| 需求               | Persona Studio                                           | MUSE                                                    | 更适合当前哪一部分                                   |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------- |
| 企业资产治理       | 人物编辑、不可变版本、素材元数据、授权状态/期限/用途校验 | 图片上传、分类、收藏、资料关联；缺正式版本和授权治理    | Persona管理流程更完整，但都只是本地Demo              |
| 需求理解和素材确认 | 有界规则解析及可编辑配置                                 | 规则候选理由、歧义确认；可配置Qwen JSON适配，未真实验证 | MUSE更适合验证自然语言选材；均非完整语义检索系统     |
| 固定人物复用       | 本地人物与版本引用，真人模型未接                         | Soul ID v2→新参考图→视频图片参考的适配代码              | MUSE更贴近Higgsfield路线；一致性未通过验收           |
| 视频生成           | Mock Provider；小云雀CLI POC及离线测试，真实入口未完成   | Seedance/Kling上传、估算、状态、取消、下载的本机适配    | MUSE更贴近本次Higgsfield账号联调；没有真实成功证据   |
| 全身、新表情、帽子 | 任务里可表达需求，实际画面未生成                         | 可提交参考图片和新提示词，效果需客户实测                | MUSE有更直接测试路径，两套均不能承诺达标             |
| 任务与审核溯源     | 状态机、四角色示意、驳回理由、审计、版本快照             | 实际API状态适配、本地审核标记、配置快照和复用           | Persona业务治理更完整，MUSE接口验证更具体            |
| 成品               | 静态占位图和JSON Mock清单                                | 内置可播放6秒样片；真实媒体预览下载适配                 | MUSE媒体流程更贴近测试；示意样片不是AI效果           |
| 账号和角色         | 四类角色切换与业务限制，无真实身份认证                   | 无正式登录和多角色权限                                  | Persona适合讨论角色，均不是生产权限系统              |
| 品牌声音与口型     | 未接                                                     | 未接，声音档案仅关联                                    | 两套都需要补声音与同步服务                           |
| 长期共享和退出     | 本机localStorage和Mock清单                               | 本机localStorage、代理JSON、单任务配置导出              | 都需要共享存储、备份与完整交接；不能导出平台人物模型 |

针对当前“客户自助工作台 + Higgsfield生成验证”，MUSE更适合作为技术验证起点。针对正式企业资产管理和审核，Persona的版本、授权、角色和审计设计更成熟，可以借鉴。建议先用MUSE确认真人与商品样片质量，再确定正式B类范围；不能将两者功能相加就宣称全部已实现。

两套都未满足零漂移、克隆原声同步、稳定全身表演、帽子零误差和模型私有化全部条件。模拟测试通过、接口适配存在、真实服务接通、内容验收通过分别记录，不混为同一完成状态。
