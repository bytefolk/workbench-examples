# MUSE 缪思 品牌数字人技术验证工作台

面向品牌内容创作者，演示图片/录音资产、候选确认、脚本、任务与成品复用。当前为 **prototype**：免费模拟可运行；有阿里云万相、声音复刻/TTS/图片对口型、Higgsfield、Qwen及小云雀适配代码。只有软件和模拟响应验证，没有真实账号成功回执或客户质量验收，不能称为 integrated。默认人物、商品和媒体全部虚构；6秒内置样片没有AI表演或克隆声音。

## 从干净检出启动

Node.js 22.12+，仓库根目录执行：

```sh
npm ci
npm run check
npm run demo
```

打开 http://127.0.0.1:4173 ，选择MUSE。目录入口只运行免费模拟，不请求任何本机API。图片与样片来自自身构建目录，浏览器存储键为 `bytefolk-brand-digital-human-studio-v1`，与Persona隔离。

## 免费演示

1. 资产库搜索、筛选、收藏或上传PNG/JPEG/WebP，最大2MB。
2. 输入虚构人名、商品编号和场景，查看候选理由，手动确认应用。
3. 编辑规则分镜、提交模拟任务，约22秒后进入成品。
4. 播放6秒示意样片，审核、下载、导出JSON和复用配置。

重置仅清浏览器记录，不取消云任务或删除云人物/声线。生产登录、企业共享、权限、队列与长期云存储未建设。原Persona案例保留，见[两套工作台对比](comparison.md)。

## 独立运行接口验证

仓库根目录执行 `npm run dev --workspace muse-digital-studio`，工作台 http://127.0.0.1:4318 ，本机代理8788。当前主测试路线为阿里云，默认关闭收费调用；目录4173永远只模拟。

在4318选择「阿里云万相真实 API」或「声音复刻与对口型」，点击「配置阿里云」，输入北京地域百炼通用API Key及可选业务空间ID。Key保存于忽略的本机后端文件，不回显、不进浏览器持久存储或配置导出；没有生产凭据加密。保存、刷新、上传录音不发起生成。每个云生成步骤由用户点击，分别计费，不自动充值或连做。

万相模型可在页面选择，时长、分辨率、声音、镜头与价格估算同步变化，后端严格提交所选模型：

| 模型             | 时长/分辨率              | 声音与镜头               |
| ---------------- | ------------------------ | ------------------------ |
| wan2.6-i2v-flash | 2–15秒，720P/1080P       | 有声/无声可选，单/多镜头 |
| wan2.6-i2v       | 2–15秒，720P/1080P       | 固定原生有声，单/多镜头  |
| wan2.2-i2v-flash | 固定5秒，480P/720P/1080P | 无声、无多镜头参数       |

默认2.6Flash、5秒无声。三款均只提交一张首帧和文字，独立人物/商品/场景三图不会同时提交。2.6合计提示词限1500字符，2.2限800字符；原生有声不等于品牌克隆声线。结果下载本机后进入任务与成品，支持播放、下载、审核和复用；模型权限、费用和效果仍需账号验证。

声音入口：上传10–20秒、≤10MB的WAV/MP3（≥16kHz，WAV16bit，无音乐和其他人声）→用户点击复刻并在平台OK后绑定人物→输入1–240字新台词，点击TTS、试听下载→点击对口型。使用 `voice-enrollment`、`qwen-audio-3.0-tts-flash`、`wan2.2-s2v`。对口型只提交人物图与新音频，小于20秒、480P/720P；不接独立帽子/场景/分镜/全身动作参数。修改人物、台词或声线后，旧语音不能用于不匹配视频。下载失败可取回原语音，不重复TTS。

Higgsfield可选：将 `workbench/.env.example` 复制为 `.env`，填写 `HF_API_KEY` 和 `HF_ENABLE_REAL=true`，重启独立服务。Soul ID v2→completed→Soul 2参考图→视频图片参考；不是把Soul ID传给任意模型。视频支持Seedance 2.0和Kling O3参考模式，分镜编译为一条短片提示词；不做逐镜生成/长片合成或任意成片声轨替换。

Qwen可选：`DASHSCOPE_API_KEY`、`QWEN_BASE_URL`、`QWEN_MODEL`，按Token计费，未配置时免费规则检索。小云雀可选：工作台目录运行 `npm run xyq:install` 和 `npm run xyq:login`，官方CLI1.0.38；需账号调用权限和积分，`XYQ_ENABLE_REAL=true` 才调用，主路线不依赖小云雀会员。

配置、状态、原录音、新语音及万相/小云雀MP4在 `workbench/.local/higgsfield-demo/`；Higgsfield仍播放平台链接，均需自行备份，不是企业永久归档。账号权限、余额、真人声线、口型、全身表演、帽子细节及一致性均待真实样片验证。云人物/声线ID不是可导出的模型权重。详见[接入说明](integrations.md)、[验收](acceptance.md)和[验证记录](evidence/verification.md)。
