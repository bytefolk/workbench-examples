# 验收条件

| 编号 | Given / When / Then                                                                | 检查方式                 |
| ---- | ---------------------------------------------------------------------------------- | ------------------------ |
| M01  | 从干净检出安装并构建 / 打开目录 / 两套工作台均能进入，原案例源码保留               | 根check、浏览器与diff    |
| M02  | 默认目录模式 / 打开资产和创作 / 图片及示意视频来自本案例路径，不发起代理或收费请求 | 浏览器资源与状态         |
| M03  | 输入虚构人名或SKU / 推荐候选并确认 / 提示理由，选择不被静默覆盖                    | 浏览器操作               |
| M04  | 模拟提交 / 等待完成 / 任务进入成品，播放内置样片，审核与复用可用                   | 浏览器操作               |
| M05  | 无真实密钥 / 提交真实操作 / 独立代理阻断收费请求，目录禁止真实调用                 | 软件测试与浏览器         |
| M06  | 模拟供应商 / 上传、提交、查询和取消 / 验证参数、会话、幂等、安全和已支持状态       | Node测试，非真实服务验收 |

真实质量验收另用授权素材，记录模型、参数、请求ID、全部候选、费用及不合格时间点：同人物新表情；全身走动/转身/坐立；帽子形状、纹理、标识和手部接触；跨场景一致性；实际视频下载和单位可用成片成本。每项先限制候选次数再评估。

声音克隆、口型、多机位、精确时长、长片合成、永久归档、生产角色与授权、人物权重导出均不能以本Demo验收通过。接口成功不是画面合格，模拟视频不是AI表演。当前没有客户确认。
