# 验收条件

| 编号 | Given / When / Then                                                       | 检查                  |
| ---- | ------------------------------------------------------------------------- | --------------------- |
| M01  | 干净安装构建 / 进入目录 / 两套案例可运行，原案例保留                      | 根check、浏览器、diff |
| M02  | 免费目录 / 访问所有模式 / 资源来自本案例，不发任何API或付费请求           | 浏览器                |
| M03  | 输入虚构人名SKU / 推荐并人工确认 / 不静默覆盖原选择                       | 浏览器                |
| M04  | 模拟任务 / 等待完成 / 样片可播放审核下载复用                              | 浏览器                |
| M05  | 无Key / 真实操作 / 本机阻断，目录禁用调用                                 | 软件与浏览器          |
| M06  | 模拟供应商 / 提交查询取消 / 合同、会话、幂等和错误正确                    | Node，非服务验收      |
| M07  | 页面Key / 保存刷新清除 / 无云调用、不回显或进入localStorage/导出          | Node与隔离浏览器      |
| M08  | WAV/MP3 / 手动复刻TTS / 就绪才绑定指定人物，语音可试听下载，不连做下一步  | Node与隔离浏览器      |
| M09  | 旧语音 / 更改人物台词声线 / 阻断不匹配对口型                              | Node与隔离浏览器      |
| M10  | 模拟供应商 / 万相或对口型 / 原任务查询、MP4留存、审核复用，不重发付费提交 | Node与隔离浏览器      |

真实质量需授权素材和账号验证，保留全部候选、参数、请求ID、费用及问题时间点：同人物新表情、全身走动转身坐立、帽型纹理标识和手部接触、跨场景稳定、真人声线相似度与口型时序、单位合格成片成本。成功返回不是质量合格；口播不替代全身验收。

声线/TTS/图片对口型已有代码和软件验证，实际账号与内容质量未验收。多机位、精确时长、长片、企业永久归档、角色授权和模型权重导出未完成。没有客户确认。
