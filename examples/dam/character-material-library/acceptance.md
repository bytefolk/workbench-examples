# 验收标准

## Persona Studio 主入口

| ID    | 当前承诺                                                   | 验证方式                     |
| ----- | ---------------------------------------------------------- | ---------------------------- |
| PS-01 | 从统一案例目录打开构建应用，本地图像与字体在子目录正确加载 | 浏览器                       |
| PS-02 | 解析、修改、确认、模拟生成、审核、归档七步链路及来源关联   | 原有浏览器测试与本次手工复验 |
| PS-03 | 素材缺失、过期或范围不匹配、角色不足、未配置渠道阻止提交   | 领域与浏览器测试             |
| PS-04 | 新增/编辑人物形成版本，素材快照不随后续修改改变            | 领域与浏览器测试             |
| PS-05 | Mock 成功、单次失败、复制重试、取消合法迁移                | 领域与浏览器测试             |
| PS-06 | 刷新保留草稿、审核和结果，模拟任务从原时间恢复             | 浏览器测试                   |
| PS-07 | 导出 JSON Mock 清单；无真实视频输出或真实费用声明          | 浏览器测试与手工检查         |
| PS-08 | 桌面与窄屏基本可读，主链路无页面异常                       | 原有浏览器测试               |
| PS-09 | CLI POC 在未授权、任务 ID 缺失、下载非视频和未知提交时停止 | 8 项本地 POC 软件测试        |

来源包的历史记录见 [ACCEPTANCE.md](workbench/docs/ACCEPTANCE.md)；归仓后的实际检查见 [verification.md](evidence/verification.md)。历史“18 项领域检查”文字与来源中的 17 个实际测试不一致，当前按实际执行报告计数。

## 以下为素材管理简版验收

下表为当前 prototype 的承诺范围，客户业务验收仍待确认。

| ID    | Given / When / Then                                                                           | 检查方法         |
| ----- | --------------------------------------------------------------------------------------------- | ---------------- |
| AC-01 | 初始合成数据 / 打开原型 / 显示 2 个人物、8 项素材及模拟说明                                   | 浏览器           |
| AC-02 | 素材列表 / 搜索林夏并筛视频 / 仅显示匹配且 active 的人物视频；无匹配有空态                    | 浏览器与业务测试 |
| AC-03 | 人物概览 / 查看林夏 / 5 种基础情绪齐全；周宁展示缺失情绪                                      | 浏览器           |
| AC-04 | active 素材 / 打开详情 / 显示关联、版本、来源、状态和允许用途                                 | 浏览器           |
| AC-05 | approved 人物及允许营销的输入 / 创建视频模拟任务 / 保存输入版本快照，显示 mock-queued，无输出 | 业务测试与浏览器 |
| AC-06 | pending 人物或输入 / 尝试创建任务 / 拒绝且说明使用范围待确认，不增加任务                      | 业务测试与浏览器 |
| AC-07 | approved 但仅 internal-demo 的素材 / 营销用途任务 / 拒绝，不增加任务                          | 业务测试         |
| AC-08 | 已归档素材或其他人物的素材 / 创建任务 / 拒绝，不增加任务                                      | 业务测试         |
| AC-09 | 未接入数字人或试戴服务 / 创建对应任务 / 提示不可用，不模拟真实输出                            | 业务测试与浏览器 |
| AC-10 | mock-queued 任务 / 模拟完成 / 显示 mock-complete，output=null，明确没有生成视频               | 业务测试与浏览器 |
| AC-11 | 已创建任务 / 归档输入素材 / 新选择列表移除素材，历史快照不变                                  | 业务测试与浏览器 |
| AC-12 | 改变本次状态 / 刷新 / 恢复固定初始数据                                                        | 浏览器           |

## 接入后的验收候选

真实媒体入库与版本回读、真实任务提交与状态恢复、生成质量、失败重试与取消、授权撤销处理、角色权限、输出审核、交付和成本记录。只有接口和客户标准明确后才将这些候选升级为正式承诺。
