# 本色 Persona Studio 实现方案

依据企业数字人资产与视频生成工作台 PRD v0.1.0，实现本地售前 Demo。

## 技术与目录

React + TypeScript + Vite，Lucide 图标，原生 CSS。无需后端或密钥。浏览器 localStorage 保存业务数据；角色切换仅为演示，不是生产鉴权。Provider 统一接口可在后续服务端替换。

```
src/
  domain/  类型、种子数据、纯业务逻辑、状态机、Provider Adapter
  components/  工作台外壳、表单、抽屉、卡片、状态、公共控件
  pages/  概览、人物资产、视频生成、生成任务、成片库、管理设置
  store.tsx  持久化、角色、集中任务推进、业务操作入口
public/images/  原创 AI 人物示意图
tests/  领域验收、浏览器端到端验收
docs/  PRD、实现方案、验收记录、图像生成提示词
```

## 页面与关键交互

概览：可复用人物、素材、任务统计，自然语言快捷入口，最近任务。人物资产：搜索与状态/授权/负责人筛选、卡片/列表、详情、素材登记、编辑、版本、停用。视频生成：模拟解析、推荐理由、可编辑配置、资产检查、提交确认。任务：状态筛选、进度、溯源、日志、复制、取消、重新生成、成功/失败模拟。成片库：静态成片占位预览、标签与审核筛选、版本与来源、审核意见、Mock 清单下载。设置：四种角色展示、Provider 开关、审核规则、审计。

## 数据与状态机

Character 的当前版本由 CharacterVersion 指向。版本含不可变素材快照与授权；任务保留人物版本、素材快照、输入请求、脚本/参数和渠道快照；GenerationResult 与 Review 独立关联。AuditLog 记录操作前后、时间、角色与原因。

状态路径：草稿 → 待确认 → 排队中 → 生成中 → 待审核 → 已完成。失败可发生于生成或审核驳回；取消只允许草稿、待确认、排队中。重试/复制创建新草稿，保留原任务。

提交时检查当前人物、授权时间/范围、核心素材、角色、当前 Provider 可用性及任务字段。复制历史任务后重新检查当前版本，禁止绕过停用和授权变更。历史快照保持不变。浏览器刷新后按持久化时间恢复模拟进度；不无限重试。

## 阶段与验收

1. 模型、数据、授权校验、状态机、Provider 和持久化。
2. 六页工作台及新增/编辑/生成/审核/归档完整交互。
3. 领域测试：授权缺失、素材不足、角色限制、快照、非法迁移、取消、成功与失败。
4. 浏览器测试：PRD 七步主链路、刷新、失败复制、权限差异、人物新增与素材登记；截图和响应式检查。

所有模型、估算和结果明确 Mock。人物图像为原创 AI 示意图，无真实客户素材。下载只导出模拟结果清单，不伪造视频文件。
