## 工作台定位

企业人物资产与授权 → 内容需求/剧本 → 小云雀生成流程 → 人工审核 → 成片归档与来源记录。

Mock Provider 继续承担首版演示。小云雀渠道显示名称、官方文档与接入状态，保持 `configured=false`、`mode=unconnected`、费用未知。启用渠道开关不能使其成为可调用能力。官网当前展示的模型版本不自动等同于客户账号或 API 可用版本。

## 服务端适配方向

使用统一 Provider Adapter 封装短剧流程；任务拆为剧本解析、素材阶段、分镜视频和合成阶段，外层仍保持工作台统一状态机。按官方示例保留 `assets_id`、`thread_id` 与 `EpisodeID` 等后续调用关联信息。实际请求 Schema、幂等规则、结果有效期、取消能力与错误映射须逐接口核对，当前未实现真实 Adapter。

真实凭据仅由服务端使用，不进入浏览器。先验证上述链路和素材复用，再决定是否扩展短剧项目、剧集和分镜编辑页面。
