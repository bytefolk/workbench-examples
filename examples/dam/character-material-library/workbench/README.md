# 本色 · Persona Studio

企业数字人资产与视频生成工作台，基于 PRD v0.1.1 的本地可交互 Demo。

现作为 [ByteFolk 首个 DAM 案例](../README.md)收录。依赖由根 npm workspace 锁文件管理，以下 npm 命令从仓库根目录执行。

```sh
npm ci
npm run persona:dev
```

打开 http://127.0.0.1:4317/。需要 Node.js 20.19+ 或 22.12+。首次安装后，所有示意图、字体和模拟生成均在本地运行，无需 API 密钥。

## 演示路径

1. 默认角色为内容创作者，进入「视频生成」。
2. 输入「用品牌主理人生成 30 秒秋季帽子试戴短片，温柔克制，竖屏」，点击解析。
3. 核对人物与授权，修改脚本/配置，确认并提交。
4. 等待约 11 秒，或点击任务详情中的「立即推进模拟」。
5. 关闭详情，右上角切换「审核人」，再次打开任务，填写意见并通过。
6. 在成片库查看已归档占位结果、素材快照与完整来源。

选择「模拟演示结果：失败」可演示单次失败与复制重试。选择周予安、Echo 或商业广告范围，可看到素材/授权拦截。切换资产管理员可新增/编辑人物、登记素材元数据、维护授权、停用人物；切换系统管理员可维护渠道开关、审核规则和重置数据。

## 实现与边界

- React + TypeScript + Vite，统一 Provider Adapter 与集中状态机。
- localStorage 保存人物、不可变版本、素材快照、请求、任务、结果、审核、渠道与审计；刷新后恢复模拟进度。不同浏览器的演示数据各自独立。
- 四种角色切换演示界面与业务层权限，不等同于真实身份认证或服务端授权。
- 客户平台已确认是小云雀，短剧方向。渠道页已补官方 API 文档，仍为待接入；账号权限、外部人物/声线复用待验证，见 `docs/XIAOYUNQUE.md`。
- 3 个人物、3 个渠道、6 个历史任务、4 个初始占位结果。预置进行中任务会自动推进，结果数量随后增长。
- 解析是有界规则模拟；推荐可编辑，缺失字段会提示。所有图像为原创 AI 人物示意图。
- 结果是静态占位图；下载导出 JSON Mock 清单，不提供或伪造真实视频。
- 费用是 Mock 估算，无真实计费；未接入渠道的价格保持未知。
- 不涉及直播、支付、真人建模、声线克隆、模型训练或私有化交付。

```sh
npm run test:cases

npm run test:e2e
npm run build
```

浏览器验收使用 Playwright Chromium。测试覆盖完整生成审核链路、授权/角色拦截、失败重试、素材与版本、刷新持久化、自动推进恢复、桌面/移动端布局及 Mock 清单导出。

PRD、实现方案、验收记录与截图位于 `docs/`，人物图与字体位于 `public/`。图像提示词见 `docs/IMAGE-ASSET.md`；字体许可证见 `public/fonts/licenses/`。
