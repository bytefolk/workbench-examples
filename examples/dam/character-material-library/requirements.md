# 需求与范围

## 来源与已知需求

来源：2026-10-13 的业务讨论文字，整理成公开案例。该来源提出以下方向，尚未获得客户确认：

- 建立内部媒体素材资产库。
- 在制作人物视频前，准备人物及喜、怒、哀、乐等基础视频素材。
- 利用人物素材生成不同动态与内容。
- 场景涉及视频生成、真人形象的数字人、主播卖货以及人物试戴产品。

原讨论中的截图未解析，客户其他资料未读取。因此本文件不声称已还原完整客户需求。以下 MVP 设计是为便于验证而提出的方案。

## 使用角色

| 角色         | 工作目标                       | 原型覆盖                                     |
| ------------ | ------------------------------ | -------------------------------------------- |
| 素材管理员   | 整理人物、素材、版本与使用范围 | 检索、详情、人物覆盖概览、归档               |
| 内容制作人员 | 为生成任务准备可用输入         | 选择人物、人物素材、产品素材与用途；模拟交接 |
| 审核人员     | 核对输入及输出是否可用         | 输入快照可查看；输出审核属于接入后范围       |

角色用于业务流程描述；原型没有账号或权限系统。

## MVP 建议

- R-01：按人物、素材名称、标签和类型检索，空结果有明确提示。
- R-02：素材详情展示人物关联、类型、情绪、版本、来源与演示使用范围。
- R-03：人物卡展示已有和缺失的基础情绪素材；“覆盖完整”仅表示 fixture 类型齐全，不表示足以训练模型。
- R-04：创建任务前，检查人物和输入素材的演示使用范围、人物归属及素材有效状态。
- R-05：任务保存稳定素材 ID、版本、人物、产品、用途和提示词；后续素材状态改变不改写历史快照。
- R-06：归档素材从新任务选择中移除；历史任务保留原输入。
- R-07：任务与完成提示明确是模拟，无视频、数字人、试戴输出。
- R-08：未接入的任务类型显示不可用原因。

## 接入后范围

真实上传和媒体预览、持久化和多人权限、异步生成、任务重试与取消、输出审核、导出和发布。接入前先确定输入规格与质量标准，不假设任意基础视频都能驱动任意模型。

## 需要客户确认

1. 最先需要跑通的是素材管理、人物视频、虚拟主播，还是产品试戴？
2. 人物素材数量、格式、时长、情绪与动作要求，以及当前存储位置是什么？
3. 使用范围、授权期限、撤销处理和审核负责人如何确定？
4. 是接现有生成服务，还是已有专用模型？预算、等待时间和质量标准是什么？
5. 产品试戴面向哪些商品，输入是图片、视频还是三维素材？
6. 是否需要接钉钉/DWS、现有 DAM、审批或电商系统？
7. 成功标准和最终人工验收人是谁？
