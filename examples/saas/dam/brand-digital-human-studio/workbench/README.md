# MUSE 工作台源码

从仓库根目录执行 `npm ci`，然后 `npm run dev --workspace muse-digital-studio`。开发入口为 http://127.0.0.1:4319 ，代理为 127.0.0.1:8788，默认不调用付费服务。

根目录 `npm run demo` 的 4173 案例入口始终只运行免费模拟，无代理依赖。配置、真实调用步骤、演示与重置方法见 [案例说明](../README.md)。

进入工作台先使用虚构公共演示账号 `admin@muse.demo`（品牌管理员）或 `creator@muse.demo`（创作成员），密码均为 `Muse2026!`。默认sessionStorage当前标签页8小时；勾选「在此浏览器记住我 7 天」使用localStorage最长7天，刷新保持，到期重新登录。登录命名空间为 `bytefolk-muse-demo-auth-v1`，输入密码不持久化。

演示身份不提供正式鉴权、RBAC或API保护；两账号使用同一浏览器工作空间。退出只清登录态，不清工作空间和供应商配置/Key，不中止云任务。2026-10-14桌面/手机登录检查和仓库5项浏览器回归通过；退出未调用清除/取消接口，没有用客户真实Key验证供应商配置恢复，见[验证记录](../evidence/verification.md)。

独立预览需要两个终端：`npm run api --workspace muse-digital-studio` 与 `npm run preview --workspace muse-digital-studio`；提前构建工作台。 `.env` 放在本工作台目录，禁止使用 `VITE_` 密钥或提交运行状态。

`npm test --workspace muse-digital-studio` 使用模拟供应商响应验证参数、安全边界和状态，不证明真实账号、扣费或生成质量。

## Seedance 视频接入

独立4319入口选择「Seedance 视频」→「配置 Seedance」，填写「接口地址（Base URL）」与独立Key，点击「保存配置」，5秒720P、文生或人物单图参考；由用户点击生成，异步任务回读和本机MP4归档。页面名称不展示聚合平台，默认Base URL为 `https://ai.amaxsmp.com/v1`，可页面配置使用同一视频协议的服务地址，不能当字节官方直连。详情见[接入说明](../integrations.md)。真实账号、Base64和下载网关待联调；无多图/音频驱动/取消/模型导出，阿里云声音配置独立保留。

网址配置版最终软件结果：本地53项（Seedance17项）、仓库MUSE54项、最终完整check与6项浏览器回归通过。网址规范化、旧任务恢复原配置、本机下载等已用隔离模拟上游验证；真实平台调用为0，真实账号/Key、Base64及内容质量未验收，见[验证记录](../evidence/verification.md)。

## 当前更新

万相页面支持官方/兼容网关协议、Base URL及可选模型别名；网关模式不支持现有百炼声音链路。真实成品封面读取视频帧，任务错误显示摘要、详情换行，资产库最近成片使用对应结果。创作页新增5秒全身案例，选择及填入不提交生成。

仓库目录入口不显示Key或真实模式，只运行合成示例与模拟流程；本机4319入口可配置自己的账号。端口4319/8788、浏览器隔离命名空间及`.local/`数据路径保持独立。配置与真实数据均不得提交，`.env.example`只含空密钥占位，所有真实调用开关默认关闭。最新软件检查见上层验证记录。
