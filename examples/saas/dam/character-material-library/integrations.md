# 能力与接入

## 主入口 Persona Studio

React + TypeScript + Vite 应用通过根 npm workspace 安装、构建与验证。原始依赖目录和 CLI 二进制不入库。Vite 使用相对资源路径，统一目录服务从构建结果打开该应用。

- 人物、素材元数据、版本与审计：本地业务逻辑。
- 需求解析、Provider、费用、生成进度、成片和角色身份：Mock 演示。
- 小云雀：未接入的渠道，`configured=false`，实际价格未知。
- 小云雀 POC：保留 CLI 调用脚本和离线测试；本机未安装/登录的能力不作成功声明。

[POC 说明](workbench/poc/README.md)列出官方 CLI 安装、登录和单任务恢复步骤，实际运行须另行授权。素材映射和回执留在忽略目录 `poc/runs/`，未知提交不会自动重发。历史接口研究和当前真实环境验收分别记录。

## 以下为素材管理简版接入边界

| 能力              | 当前模式    | 当前行为                                         | 接入需要                                                 |
| ----------------- | ----------- | ------------------------------------------------ | -------------------------------------------------------- |
| 素材检索与详情    | local       | 固定 JSON 数据、浏览器内存处理                   | 正式查询 API、分页与存储                                 |
| 生成任务准备      | mock        | 校验合成使用范围、保存输入快照、人工推进模拟完成 | 持久化、任务服务、审核与状态回读                         |
| 视频生成          | unavailable | 可准备对应模拟任务，不生成媒体                   | 提供商、人物输入要求、异步 API、输出格式、费用与质量标准 |
| 真人形象数字人    | unavailable | 创建时提示未接入                                 | 建模/驱动服务、人物输入及使用范围                        |
| 产品试戴          | unavailable | 创建时提示未接入                                 | 支持的商品类目、人物/产品输入、服务和结果标准            |
| DWS / SaaS 连接器 | unavailable | 不读取或写入钉钉及其他 SaaS                      | 明确目标系统、身份、权限和接口契约                       |
| 数字员工编排      | unavailable | 原型不运行 Agent                                 | 确定执行岗位、任务输入输出、运行宿主和配置               |

## 建议的接入边界

工作台调用自己的业务服务。媒体、模型和 Agent 凭据保留在服务端，浏览器不直接持有。连接器在任务服务边界适配选定提供商，不在未确定服务前规定一个虚假的通用 API。

真实接入需要将任务 ID 与提供商请求 ID 关联，通过轮询或回调回读状态；失败、超时、限流、取消和审核不通过要在工作台可见。结果文件保存后才展示为可预览或下载的输出。

## 配置

当前没有环境变量、密钥或 SaaS 账号要求。`npm run demo` 只启动 127.0.0.1 上的本地静态服务，默认端口 4173，可通过 `PORT` 指定其他端口。

真实服务的配置样例与验收证据在实际实现时补充；当前没有已验证提供商，也没有模型质量结论。
