## 接口结论

人物照片与 WAV/MP3 参考音频可以经官方 CLI 上传并作为生成参考。角色画布 Schema 有主图、音频和 Voice ID 引用字段。

仍不能承诺上传一次永久复用：现有视频直出命令逐次上传本地素材，素材 ID 保留期限、跨任务/项目引用和企业团队权限尚未实测。真人克隆声线创建接口及声音跨任务一致性也未确认。

火山公开短剧 API、小云雀 CLI 与火山「剧创」是不同入口，不能互相继承能力验收。详细证据和官方来源见 `XIAOYUNQUE-API-RESEARCH.md`。

## 接下来做什么

1. 用目标小云雀账号运行 `pippit-tool-cli login` 完成网页授权，再检查 `status`。不要把密钥贴到聊天。
2. 查询实际模型与参数、积分，选择账号可用模型；准备已授权的测试人物照片和参考音频。
3. 按 `poc/README.md` 上传并回读素材，保存真实 ID；提交一个任务，保留 thread/run/link，查询并取得真实成片。
4. 检查实际时长、人物、帽子细节、声音，再进行第二条任务的 ID 复用和跨日回读；保留期限最终需平台确认。
5. 只有真实调用和结果取得完成后，才把渠道标记为可用。当前 `configured=false`，演示继续为 Mock。
