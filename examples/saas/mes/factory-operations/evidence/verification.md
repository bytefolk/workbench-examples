## 云端 10 组覆盖

执行 [cloud-smoke.mjs](../workbench/scripts/cloud-smoke.mjs)，`FACTORY_SMOKE_CONFIG` 指向仓库外的本地账号配置。程序逐项检查并回读服务端结果：

1. 两个独立测试账号真实登录。
2. 创建工作区，创建者成为所有者，重新查询可读取。
3. 非成员读取其他工作区无数据，向该工作区写入被拒绝。
4. 上传私有 PNG，列出资产、授权下载并比对原始字节；非成员无法取得该文件的访问授权。
5. 断针缺少照片被拒绝，携带真实上传照片的断针申领成功落库。
6. 同一审批请求重放不重复推进版本；不同请求使用旧版本被拒绝。
7. 未回收的断针禁止完结；审批、配送、回收、完结全流程成功，含首次提交共五条审计事件。
8. 写入销售拜访，再查询可读回客户纪要、问题、下一步和跟进日期。
9. 所有者加入已注册操作员；该操作员不能添加成员、审批或读取销售拜访。
10. 退出并重新登录后，已完成单据仍能从数据库读回。

验证完成后已删除两个专用测试账号、两个测试工作区及其业务数据，并通过 Storage API 删除两个测试文件；回查测试账号、工作区和存储对象均为零。本机测试账号配置也已删除，工作台保留所选部署的公开连接配置，供真实用户自行注册登录。其他部署可按 [集成说明](../integrations.md) 复用检查。

## 验证中修复的问题

最初版本把业务版本冲突标为 PostgreSQL `40001`（序列化失败），真实检查时冲突请求返回缓慢。第三个迁移改用 `PT409`，将业务冲突明确返回 HTTP 409；适配器关闭默认数据库请求重试，并设置网络超时。修复后重新执行完整云端流程，10 组全部通过。

平台预置自动 RLS 事件触发函数不需要由浏览器角色直接调用。第二个迁移收紧其执行权限，两条相关安全 advisor 告警在复查中消失。

## 当前限制

- 已验证登录与会话持久化；未验证外部邮箱注册邮件投递。Supabase 默认发信仅面向组织成员邮箱，对其他用户开放前需配置自有 SMTP，见 [集成说明](../integrations.md)。
- 安全 advisor 仍报告平台的泄漏密码保护未启用；本次没有把该账号安全能力声明为已启用。
- HTTP 适配器通过本地契约测试；没有部署 MySQL 服务或接入企业资产平台，不能把它们标为 `connected`。
- AI 总结、语音/图片识别和钉钉通知未接入，没有伪造执行结果。
- 当前批量列表读取超过 10000 条会明确报错；尚无服务端筛选/分页浏览界面。资产预览使用 300 秒授权地址，过期后需重新获取。
- 客户需求完整确认、人工正式验收、业务保留策略与生产运维验收尚未完成。
