# SaaS 与行业场景分类

主分类回答“这项工作主要管理什么业务对象”。每个案例只有一个主领域，跨领域通过 tags 描述。领域目录仅在有实际案例时创建。以下候选方向是分类说明，不代表已交付。

| ID        | 领域               | 主要业务对象               | 候选工作台                   |
| --------- | ------------------ | -------------------------- | ---------------------------- |
| crm       | 客户与销售 CRM     | 客户、联系人、商机、跟进   | 销售跟进、客户画像、商机推进 |
| erp       | 企业资源 ERP       | 订单、采购、库存、资源核算 | 采购协同、订单履约、经营管理 |
| mes       | 制造执行 MES       | 工单、工序、在制品、产线   | 排产、生产异常、质量追溯     |
| wms       | 仓储物流 WMS       | 库位、出入库、盘点、拣配   | 仓库运营、盘点、拣货         |
| scm       | 供应链与供应商 SCM | 供应商、供应计划、交付     | 供应商协同、供需计划         |
| hrm       | 人力资源 HRM       | 员工、招聘、入职、绩效     | 招聘、入职、人员服务         |
| finance   | 财务与费用         | 应收应付、费用、预算       | 回款、报销、费用控制         |
| oa        | 办公与审批 OA      | 审批单、通知、办公申请     | 审批处理、行政服务           |
| itsm      | IT 服务与运维 ITSM | 服务单、设备、事件、变更   | 服务台、设备管理、故障处理   |
| projects  | 项目与研发协作     | 项目、任务、需求、交付     | 项目进度、研发交付           |
| analytics | 数据分析 BI        | 指标、数据集、分析结果     | 经营指标、异常分析           |
| dam       | 数字资产管理 DAM   | 人物、图片、视频、素材版本 | 人物素材资产库、品牌素材库   |
| cms       | 内容与知识管理 CMS | 内容、知识条目、发布版本   | 内容编辑、知识维护           |
| marketing | 营销与内容制作     | 活动、创意、渠道、制作任务 | 创意生产、投放素材、营销计划 |
| commerce  | 电商与零售         | 商品、门店、交易、售后     | 商品运营、门店运营           |
| service   | 客户服务           | 服务请求、知识、反馈、工单 | 售后服务、客服质检           |

## 分类边界

- CRM 关注商机与客户关系；service 关注受理和解决服务请求。
- ERP 涉及整体资源与订单；MES 关注生产执行；WMS 关注仓内作业。
- DAM 关注资产沉淀、检索、版本与使用范围；marketing 关注活动与制作交付。人物素材资产库归 DAM，带 `marketing`、`video-generation`、`digital-human`、`virtual-try-on` 标签。
- 行业、角色、技术、部署方式都用 tags，如 `manufacturing`、`sales-manager`、`dingtalk`、`self-hosted`，不复制同一案例到多个主目录。
- 业务分类不决定接入哪个 SaaS 厂商。同一业务案例可以有多个明确记录的连接器。
